Monitor Capacity Utilization Across Work Centers
[IMAGE: shots/gxm-visualize-capacity-and-utilization.png]
The dashboard consolidates capacity requirements, available capacity, backlog, and overload/underload thresholds into matrix and list views by work center and period (daily, weekly, monthly). Users can toggle between load, offer, remaining capacity, order quantity, and operation count views.
Color-coded overload logic highlights red (over capacity) and green (available capacity) directly within the matrix. Capacity period views allow drill-down into exact orders driving overload.
Schedule Directly Within a Drag-and-Drop Planning Table
[IMAGE: shots/gib-gxm-drag-and-drop-scheduling.png]
Schedulers access a structured planning table where operations can be moved, sequenced, and reallocated across periods or work centers. Orders can be repositioned interactively based on real capacity availability.
The planning table connects production orders, planned orders, work center capacities, order pool, and area-specific layouts.
Manage Shifts, Breaks, and Capacity Constraints
[IMAGE: shots/gib-gxm-capacity-and-shift-management.png]
GIB allows planners to adjust working times, shift models, and operation durations directly within the scheduling view. Setup, machine, and labor times can be modified at the operation level, and non-working time or maintenance windows can be inserted without leaving the cockpit. Capacity adjustments immediately update the schedule, allowing planners to test realistic production scenarios and resolve overloads without separate configuration steps in SAP.
Execute Production Actions Directly from the Schedule
[IMAGE: shots/gib-gxm-dcp-execute-order-conversion.png]
GIB embeds production order management directly within the scheduling cockpit. Planners can convert planned orders, adjust capacity, run heuristics, deallocate operations, and review pegged requirements without navigating across multiple SAP transactions. Execution steps that typically require separate screens are consolidated into the scheduling environment, allowing planners to analyze impact and take corrective action in one continuous workflow.
Manage Bulk, Container, and Pegged Orders in One View
[IMAGE: shots/gxm-dcp-bulk-container-and-pegged-orders-highlighted.png]
GIB provides a consolidated view of pegged requirements and bulk or container order relationships. Planners can see how bulk production quantities are allocated to dependent materials, trace multi-level order linkages, and evaluate supply alignment across finished and semi-finished goods. This improves transparency in environments with packaging splits, container production, or shared bulk processes, reducing misallocation and improving execution reliability.
